Steps to execute the project:
 1. Start the Docker Desktop running in the background 
 2. Open Terminal , cd<project directory path>
 3. Execute : docker-compose up --build ,to build the docker image
 4.After the docker built up , we can access the mlflow UI for         monitoring the model's logs and Streamlit link to use the application.

By this way we can implement MLOPs in local environment
